# 🔐 SecureVault

A full-stack Password Vault & Credential Management System built using React, Spring Boot, and PostgreSQL.

## 🚀 Features Completed

### ✅ Task 1
- User Registration
- User Login
- Password Encryption (BCrypt)
- PostgreSQL Integration

### ✅ Task 2
- Forgot Password
- OTP Generation
- OTP Verification
- Email Integration using Gmail SMTP
- Password Reset

## 🛠 Tech Stack

### Frontend
- React.js
- Bootstrap
- Axios

### Backend
- Spring Boot
- Spring Security
- Spring Data JPA

### Database
- PostgreSQL
